#### FAQ

**Why pay when the audit skills are free?**
Core tells you where you stand. Pro is for acting on it — migrations, governance, release gates — and for staying current: the ecosystem this pack drives (DTCG, Figma MCP, Claude Code) changes monthly, and so does Pro.

**What happens if I cancel?**
Your access to updates ends after a 30-day grace period. Everything the pack ever produced — reports, plans, documentation — is yours, unrestricted, forever.

**Is this built on open source?**
Yes — Muteform DS Ops is built on Design System Ops by Murphy Trueman (MIT), and our free core stays MIT. We're open about this: what you're paying for is the operational suite, the update cadence, and the hosted layer we're building on top.

**Do you train on my code?**
No. The optional, off-by-default telemetry collects anonymised aggregate metrics only (counts and scores, never code, never tokens). It powers the percentile benchmarks in the Muteform Index.
